# Sprachpakete für die Bildschirmtastatur

Wortlisten für die Wortvorschläge. Die Tastatur lädt sie nur, wenn man in den Einstellungen
auf "Weitere Sprachen herunterladen" klickt, und prüft dabei Größe und SHA-256-Prüfsumme
aus `index.txt`.

Format jeder Liste: erste Zeile `#sprache<TAB>kürzel<TAB>Name`, danach `Wort<TAB>Häufigkeit`.

Häufigkeiten aus [wordfreq](https://github.com/rspeer/wordfreq) (Daten unter CC BY-SA 4.0),
Schreibweise geprüft mit hunspell-Wörterbüchern.
